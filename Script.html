Volatility Accumulation Manager (VAM)

A portfolio and strategy calculator for spot crypto traders who buy in stages, take profit on strength or sideways moves, and track each entry separately. It is a calculator, not financial advice. It never says a lower price makes a buy safer, and it never places trades.

Link it to the site

<script src="vam-tool.js"></script>

<!-- any nav item, button or link -->
<a data-open-vam href="#vam">Accumulation Manager</a>

The tool opens as a full-screen panel above the page. It never touches the chart engine, so the existing charts keep running behind it. MPV_VAM.open(), .close() and #vam in the address also work. You can also load it inside start() next to tools-4.js; every name is wrapped in its own scope.

Optional settings, set before the script loads:

window.MPV_VAM_CONFIG = {
  navSelector: '#nav-tools',     // adds a nav item to this container
  fallbackButton: false,         // hide the small launcher once your nav item exists
  chart: () => ({coin:'BTC', tfSec:3600, candles}),   // feed the active chart
  getCandles: (coin, iv, limit) => Promise,          // use your own market-data service
  getPrice: coin => number,
  openChart: coin => {...},      // the "Open chart" button (also fires event mpv:open-chart)
  zIndex: 9000
};

Colours follow your theme if you define --vam-bg, --vam-panel, --vam-line, --vam-text, --vam-up, --vam-down, --vam-accent; otherwise a dark trading palette is used.

Where the data comes from

Trades: typed in by hand and stored in this browser only (Export / Import backup in Risk & Settings). Prices and candles: the active chart when it shows the same coin and timeframe, otherwise Binance public market-data endpoints (no key). A manual price can override any coin. No API keys are asked for; if you add account access later, use read-only keys with withdrawals disabled.

How the numbers work

Cost basis of an entry = amount + fee. Weighted average price = money spent on remaining coins ÷ remaining coins. Break-even = average cost incl. fees ÷ (1 − sell fee %). Target price (net mode) is the price where profit after buy and sell fees equals the target %. Exposure = invested cost ÷ (invested cost + cash). Portfolio value = cash + open positions at the current price; a coin with no price is valued at cost until a price loads.

Selling from the whole position lets you pick which entries the coins come from (oldest, highest-priced, lowest-priced, or proportional). Editing or deleting an entry recalculates everything that depends on it.

Risk rules

Rules warn before an entry is recorded or simulated: reserve, max entries, max exposure, max per buy, stop-adding when the position is down by your limit, minimum gap between entries, optional "needs a consolidation range" and "BTC bearish". Alerts such as drawdown, new low below the last swing low, recovery from a low, sideways range, volatility or volume spike are conditions, not signals. Averaging down adds money to a position that is already losing; losses can keep growing.
